# Manchester United VS Code Theme ❤️⚽️

A clean, modern VS Code theme inspired by Manchester United’s iconic colors — **red**, **black**, **white**, and **gold**. Includes **Dark** and **Light** variants with balanced contrast and polished workbench colors.

## Features
- 🎨 Two variants: **Manchester United Dark** & **Light**
- 🔴 Classic Red accents with Gold highlights
- 👁️ Eye-friendly, accessible contrast
- 🧩 Workbench polish (tabs, sidebar, status bar, git, terminal)
- 🧠 Thoughtful syntax hues for strings, keywords, functions, types, vars

## Install
- **Marketplace**: Search for “Manchester United VS Code Theme”  
- **VSIX**: `vsce package` → Install from VSIX in VS Code

## Use
1. Cmd/Ctrl + Shift + P → **Preferences: Color Theme**  
2. Choose **Manchester United Dark** or **Manchester United Light**
